# Fish Diversity from Passive Acoustic Monitoring

Predicting fish biodiversity from underwater soundscapes. This repo pairs about one year of weekly hydrophone recordings from a single seagrass site with concurrent seine haul surveys, and evaluates whether learned representations of the soundscape can estimate rarefied Shannon diversity.

Research collaboration between the School of Data Science, University of Virginia, and the Marine Science Department, Eckerd College.

**Authors:** Rameez Ali, Chloe Barnes, Sheyi Faparusi, Donald E. Brown (UVA School of Data Science); David Durieux (Eckerd College Marine Science)

## Overview

Passive acoustic monitoring (PAM) is a non-invasive alternative to net- and camera-based fish surveys, but most fish vocalizations have never been matched to a species, so species-level acoustic ID isn't possible at scale. This project instead reads the soundscape holistically: five neural architectures are trained directly on spectrograms and compared under recording-level cross-validation; the strongest model's out-of-fold predictions are then supplied as a feature to tree-based regressors trained on 37 hand-crafted acoustic indices.

Key findings:
- Bidirectional recurrent models (GRU, LSTM) outperform convolutional models (CNN, ResNet, DenseNet) on the same spectrogram input.
- Feeding the strongest recurrent model's out-of-fold prediction into a tree-based regressor improves every configuration tested (Random Forest / XGBoost × full / reduced feature set).
- That improvement is larger the smaller the surrounding feature set — with only 72 recordings, a large hand-crafted feature set dilutes rather than complements the learned representation.
- Audio alone explains roughly a quarter of the variance in fish diversity; the majority remains unexplained by acoustics alone.

## Data

75 audio recordings were collected weekly over one year, day/night pairs at the same site. 3 are audio-only with no corresponding seine haul; the remaining **72 recordings with matched fish count data** are what's used for modeling throughout the pipeline.

- **`Final_Fish_counts.csv`**: per-recording fish counts by species from seine haul surveys, one row per recording (the 72 recordings with matched audio, day/night pairs across ~weekly sampling dates).
- **`merged_features.csv`**: the full feature table used for modeling: acoustic features extracted per 10-second clip (2,670 clips across the 72 matched recordings), joined with per-recording fish counts, rarefied Shannon diversity (`shannon_rare_no_anchoa`), rarefied species richness (`richness_rare_no_anchoa`).
- **`merged_features_with_pred.csv`**: `merged_features.csv` plus the GRU out-of-fold prediction column (`shannon_pred_gru`), generated by notebook 07 and used as an input feature for the tree-based models in notebooks 08 and 09.

Raw audio is not stored in this repo; it's downloaded from a shared Google Drive folder (see notebook 01) into local scratch storage.

## Pipeline

Notebooks are numbered in run order. Each stage's output feeds the next.

| # | Notebook | Purpose |
|---|----------|---------|
| 01 | `01_download_audio.ipynb` | Downloads raw `.wav` recordings from the shared Drive folder into local scratch storage, with retry/resume logic. Run once before anything else. |
| 02 | `02_exploratory_analysis.ipynb` | Exploratory analysis of the raw recordings and fish count data. |
| 03 | `03_make_spectrograms.ipynb` | Builds spectrograms and the 37 hand-crafted acoustic features (RMS, ZCR, click/event statistics, spectral shape, ACI/ADI/entropy, band energy fractions, 100 Hz power bins) from the cleaned audio; writes `merged_features.csv`. |
| 04 | `04_train_cnn.ipynb` | Trains the image-style spectrogram models: CNN, ResNet, DenseNet. |
| 05 | `05_train_rnn.ipynb` | Trains the sequence-style spectrogram models: bidirectional LSTM and bidirectional GRU. |
| 06 | `06_results_summary.ipynb` | Aggregates and compares all five neural architectures across seeds/folds. |
| 07 | `07_gru_predictions.ipynb` | Trains the winning architecture (bidirectional GRU) with repeated cross-validation, writes out-of-fold predictions to `merged_features_with_pred.csv`, and runs residual autocorrelation diagnostics (All/Day/Night) on the GRU model itself. |
| 08 | `08_tree_models.ipynb` | Trains Random Forest and XGBoost on the acoustic features (full 37-feature set and a reduced 5-feature set), with and without the GRU prediction as an added feature. |
| 09 | `09_residual_diagnostics.ipynb` | Computes ACF/PACF on the residuals of the Random Forest and XGBoost models from notebook 08. |

## Preprocessing notes

- Audio band-limited to **100–2000 Hz**: excludes snapping shrimp crackle (dominant above this range) while covering where fish vocalizations concentrate.
- Boat noise flagged via two-stage manual review; affected clips are deleted rather than filtered.
- Spectrograms: 6 kHz sample rate, 10-second clips, Hann window, 1024-point FFT, 256-sample hop (~170 ms/frame, 75% overlap). Window size confirmed insensitive between 32–341 ms; 1024/256 fixed for all experiments.
- Cross-validation is recording-level (not clip-level) throughout, repeated across 5 seeds, and out-of-fold in every stage — a prediction never comes from a model that saw that recording during training.
